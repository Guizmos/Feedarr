# Configurer Feedarr

Créez le premier compte administrateur, puis configurez librement vos sources, métadonnées et applications Arr depuis leurs pages existantes. Aucun wizard n’est nécessaire.

Consultez le [guide de sauvegarde et restauration](configuration-backup.md). Les migrations des bases installées sont conservées ; les anciens formats d’archives ne sont plus importés.
